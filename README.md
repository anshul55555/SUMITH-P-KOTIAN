# Sumith P Kotian — Streamlit Portfolio

A cinematic black-gold Streamlit portfolio for a freelance video editor.

## Run Commands

```bash
cd streamlit_video_editor_portfolio
pip install -r requirements.txt
streamlit run app.py
```

Open the local URL shown by Streamlit, usually:

```text
http://localhost:8501
```

## What is included

- Default profile photo already loaded from the start
- Automotive Cinematic Reel video already added under Selected Works > Portfolio
- Navbar buttons for Home, About, Experience, Skills, Portfolio, and Contact
- No visible HTML code on the interface
- No portfolio controls/sidebar
